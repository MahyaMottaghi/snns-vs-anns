
## Energy–Latency–Accuracy Trade-offs for SNNs vs ANNs

This project compares spiking neural networks (SNNs) and artificial neural networks (ANNs) using a unified evaluation of:

- accuracy
- inference latency
- energy consumption

Experiments will run on UTSA ARC HPC GPU/CPU nodes using matched architectures and datasets.
